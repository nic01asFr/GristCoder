{{/*
Onyxia affiche ce fichier en markdown dans la fenetre du service. Regles verifiees
dans l'interface par le chart n8n-onyxia, le 11/09/2026 :
  - le bouton « Ouvrir » suit la premiere URL d'Ingress citee ici. Onyxia prend
    l'URL suivie de tout ce qui n'est ni espace ni « ) » : le texte d'un lien ne
    doit donc pas etre l'URL elle-meme ;
  - le bouton « Copier le mot de passe » cherche « password: <valeur> » : cette
    ligne reste sans mise en forme ;
  - la fenetre est etroite : une URL longue va dans un bloc de code, qui defile.
Ces notes sont conservees par Helm dans le Secret de la release. Elles affichent
la garde du pod : c'est un filtre, pas un secret — elle finit de toute facon dans
l'URL du widget, lisible par les collaborateurs du document.
*/}}
{{- $base := printf "https://%s" (include "grist-coder.hostname" .) -}}
{{- $garde := .Values.appAuth.token -}}
{{- $site := .Values.grist.siteUrl | default "https://grist.numerique.gouv.fr" -}}
### Grist Coder est lancé

- Serveur : [ouvrir la page d'accueil]({{ $base }}/)

### URL widget Grist (copier-coller)

Dans le document : **Ajouter** > **Ajouter une page** > **Personnalisé** >
**URL personnalisée**. Collez l'adresse ci-dessous telle quelle, puis choisissez
**Accès complet au document**.
{{- if $garde }}

```
{{ $base }}/?app_token={{ $garde }}
```

Sans `?app_token=`, le point du widget reste rouge.

Garde seule (en-tête MCP `X-App-Token`) / password: {{ $garde }}
{{- else }}

```
{{ $base }}/?app_token=<garde du pod>
```

La garde a été tirée au sort au déploiement. Pour la lire :

```
kubectl get secret {{ include "grist-coder.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.APP_AUTH_TOKEN}' | base64 -d
```
{{- end }}

### Config MCP Claude Code / Cursor (copier-coller)

Remplacez `VOTRE_CLE_API_GRIST` par votre clé (Grist → Paramètres du profil → API).
{{- if $garde }}
Même contenu en JSON : `curl -sH "X-App-Token: {{ $garde }}" {{ $base }}/setup.json`
{{- end }}

{{- if $garde }}

```json
{
  "mcpServers": {
    "grist-coder": {
      "type": "http",
      "url": "{{ $base }}/mcp",
      "headers": {
        "Authorization": "Bearer VOTRE_CLE_API_GRIST",
        "X-Grist-Site": "{{ $site }}",
        "X-App-Token": "{{ $garde }}"
      }
    }
  }
}
```
{{- else }}

```json
{
  "mcpServers": {
    "grist-coder": {
      "type": "http",
      "url": "{{ $base }}/mcp",
      "headers": {
        "Authorization": "Bearer VOTRE_CLE_API_GRIST",
        "X-Grist-Site": "{{ $site }}"
      }
    }
  }
}
```

Si la garde du pod est active, ajoutez `"X-App-Token": "<garde>"` (commande kubectl ci-dessus).
{{- end }}

**Alternative** — Claude Desktop / claude.ai : connecteur personnalisé, URL
`{{ $base }}/mcp`, clé Grist une fois au consentement OAuth (sans `.mcp.json`).
