GristCoder MCP est deploye.

1. URL de ton serveur (privee, protegee par owner-lock + Bearer) :

     https://{{ .Values.app.host }}

2. Recuperer la garde Bearer de TON pod (jamais connue de l'auteur du chart) :

     kubectl get secret {{ include "grist-coder.fullname" . }} \
       -o jsonpath='{.data.APP_AUTH_TOKEN}' | base64 -d ; echo

3. Cote widget Grist : ajoute un widget personnalise pointant sur

     https://{{ .Values.app.host }}/

   et renseigne le token ci-dessus dans les options de section (champ appToken).

4. Connexion client MCP — deux chemins au choix :

   (a) CONNECTEUR OAuth (recommande en ligne, Claude Desktop / claude.ai) :
       Ajoute un connecteur personnalise et colle simplement l'URL du serveur :

         https://{{ .Values.app.host }}/mcp

       Le navigateur s'ouvre sur la page de consentement de TON pod : colle ta
       cle API Grist (Grist > Profile settings > API key). Le connecteur ne recoit
       qu'un jeton revocable ; ni la cle Grist ni l'APP_AUTH_TOKEN n'y transitent.
       (Owner-lock applique : seul le compte proprietaire du pod est accepte.)

   (b) HEADERS statiques (Claude Code / .mcp.json) :

         {
           "mcpServers": {
             "grist-coder": {
               "type": "http",
               "url": "https://{{ .Values.app.host }}/mcp",
               "headers": {
                 "Authorization": "Bearer <ta_cle_api_grist>",
                 "X-App-Token": "<APP_AUTH_TOKEN etape 2>"
               }
             }
           }
         }
