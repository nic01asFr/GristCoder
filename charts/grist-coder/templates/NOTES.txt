Onyxia affiche ce fichier en markdown dans la fenetre du service. Regles verifiees
dans l'interface par le chart n8n-onyxia, le 11/09/2026 :
  - le bouton « Ouvrir » suit la premiere URL d'Ingress citee ici. Onyxia prend
    l'URL suivie de tout ce qui n'est ni espace ni « ) » : le texte d'un lien ne
    doit donc pas etre l'URL elle-meme ;
  - le bouton « Copier le mot de passe » cherche « password: <valeur> » : cette

  - la fenetre est etroite : une URL longue va dans un bloc de code, qui defile.
Ces notes sont conservees par Helm dans le Secret de la release. Elles affichent
la garde du pod : c'est un filtre, pas un secret — elle finit de toute facon dans

### Grist Coder est lancé

- Serveur : [ouvrir la page d'accueil]({{ $base }}/)

### Brancher le widget dans un document Grist

Dans le document : **Ajouter** > **Ajouter une page** > **Personnalisé**, puis
**URL personnalisée**. Collez cette adresse, garde comprise :
{{- if $garde }}

```
{{ $base }}/?app_token={{ $garde }}
```

Choisissez le niveau d'accès **Accès complet au document**. Sans la partie
`?app_token=`, le point du widget reste rouge : il ne se connecte pas.

Garde seule, pour un client MCP (en-tête X-App-Token) / password: {{ $garde }}
{{- else }}

```
{{ $base }}/?app_token=<garde du pod>
```

La garde a été tirée au sort au déploiement. Pour la lire :

```
kubectl get secret {{ include "grist-coder.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.APP_AUTH_TOKEN}' | base64 -d
```
{{- end }}

### Propriétaire du pod
{{- if .Values.security.ownerUid }}

Seul le compte Grist n° {{ .Values.security.ownerUid }} peut utiliser ce pod.
{{- else if .Values.grist.apiKey }}

Le propriétaire est le compte de la clé API Grist fournie.
{{- else if eq .Values.security.ownerLock "on" }}

**Attention** : aucun propriétaire n'est désigné. Le premier compte Grist
vérifié qui ouvrira le widget deviendra propriétaire, et à nouveau après
chaque redémarrage. Ouvrez-le vous-même en premier, ou renseignez
l'identifiant de votre compte dans l'onglet **Sécurité**.
{{- else }}

Verrou propriétaire désactivé : tout compte Grist vérifié peut utiliser ce pod.
{{- end }}
